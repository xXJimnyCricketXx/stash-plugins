## <img src="https://api.iconify.design/lucide/book-open.svg?color=%23644D3F" width="20"> Overview

This repository bundles my plugins for **Stash** in one place.
All plugins are published through one plugin source, so you only need to add a single
URL to Stash to install and update any of them.

Each plugin lives in its own folder under [`plugins/`](plugins) and has its own README
with features, screenshots and configuration.

## <img src="https://api.iconify.design/lucide/rocket.svg?color=%23644D3F" width="20"> Installation

1. In Stash, open **Settings → Plugins → Available Plugins** and click **Add Source**.
2. Enter:

   | **Field** | **Value** |
   | :--- | :--- |
   | Name | `JimnyCricket` |
   | Source URL | `https://xxjimnycricketxx.github.io/stash-plugins/index.yml` |

3. Select the plugins you want and click **Install**.
4. Reload the Stash page in your browser.

Updates appear in the same place under **Installed Plugins → Check for Updates**.
