# Grouped Tags View

Stellt die Tags-Seite von Stash als gruppierte Galerie dar: Jeder Parent-Tag wird
zur Gruppenüberschrift, darunter erscheinen seine Child-Tags als Bildkarten.

Das Plugin ist rein visuell und read-only – es nutzt ausschließlich die in Stash
gepflegten Tags und Parent-/Child-Beziehungen und verändert keine Daten.
